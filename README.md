## ✨ Design Philosophy & UI/UX

Our platform is built with a **Design-First** approach. We believe that a beautiful, distraction-free environment is essential for peak performance.

- **Glassmorphism Aesthetics**: Modern frosted-glass overlays and subtle background blurs for a premium depth effect.
- **Dark Mode First**: Optimized for long study sessions with a curated dark color palette that reduces eye strain while maintaining high contrast.
- **Dynamic Micro-Interactions**: Smooth transitions, hover effects, and scale animations that make the interface feel alive and responsive.
- **Bento Grid Layout**: A clean, structured dashboard that organizes complex data into intuitive, bite-sized components.
- **Mobile First**: A fully responsive architecture that preserves the premium feel across all devices.

## 🛠️ Key Features

- **Timed Simulations**: Realistic exam interface with section-wise timers and automatic submission logic.
- **Interactive Question Palette**: Track your progress in real-time with status-aware question navigation.
- **Review System**: Mark questions for review with a dedicated "Flag" system, just like the real exams.

### 📊 Deep Analytics
- **Step-by-Step Logic**: Every question comes with a logical breakdown to ensure you learn while you practice.
- **Performance History**: Visual tracking of your score evolution over time.
- **Subject Analysis**: Detailed breakdown of strengths and weaknesses across mathematical, logical, and technical sections.

### 🤝 Collaborative Learning
- **Study Partners**: Connect with other students, send friend requests, and build your study network.
- **Real-Time Chat**: Integrated chat system to discuss strategies and share insights with your partners.

### 📂 Personal Document Cloud
- **Smart Notes**: A robust markdown-inspired note-taking system.
- **File Management**: Upload study materials and organize them into folders.
- **Privacy & Security**: Secure storage powered by Google Cloud, ensuring your data is always safe.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- Firebase Account

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/mock-test-engine.git
   cd mock-test-engine
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file in the root and add your Firebase configurations:
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
   VITE_FIREBASE_PROJECT_ID=your_project_id
   ...
   ```

4. **Launch Development Server**
   ```bash
   npm run dev
   ```
